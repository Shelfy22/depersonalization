Окружение: Windows x64, Python 3.11.7, CPU, Torch 2.15.0, Transformers 4.57.6,
GLiNER 0.2.30. Установленные пакеты: `requirements.windows-py311.txt`.

- `python -m ruff check app scripts tests`: успешно.

- `python -m pip check`: зависимости совместимы.
- Настоящие ruBERT и GLiNER загружены из локального кеша с `HF_HUB_OFFLINE=1`.
